      🎲 Roll the Dice — the biggest money on the board right now

      Sweeps several product categories of real eBay sold history at once, keeps only the products with a genuine margin and genuine demand, then hunts for where each one can be bought today. Add your zip code to include Craigslist and Facebook Marketplace supply, not just eBay. Roll again sweeps different categories every time.

      Resale prices are real eBay sold comps (the sold-comps database, blended with Terapeak where both have data) — never asking prices. Profit subtracts eBay's standard final value fee and the shipping the comps show buyers paying. Max to pay is the price where the flip breaks even; target is what it takes to clear $75 net at 75% ROI — the same bar Local Deals calls a goldmine. A short board is the guards working, not an empty market: accessories, lots, broken-item comps and anything that hasn't sold in four months are dropped before pricing; a product needs at least five sold comps to appear at all; and supply priced under a quarter of what the product itself sells for is rejected rather than booked as profit, because in practice it's a spare part, an empty box or a broken unit. Nothing here accounts for your drive, your time, or a used item not being what the photo says — verify condition before you buy.

      Offers to Watchers

      👁 Turn Watchers Into Buyers

      Finds every live listing someone is watching, then sizes a private discount for those watchers — deep enough to close, never below your break-even plus the profit you want to keep. Your public price never moves, and if nobody accepts, it costs you nothing. Nothing reaches eBay until you confirm it.

      Nothing selected.
      Somebody is already interested. Go get them.

      Scanning reads your live listings, counts who is watching each one, and works out the discount that converts a watcher without eating the profit — checked against what you paid.

      Read-only. No offer is sent until you confirm it.

      eBay decides which listings can carry an offer and how long each one lasts (about 48 hours). Offers go to the people watching a listing, so watcher counts come from eBay and change by the hour. Break-even uses the cost basis recorded in Inventory Health plus the fee assumptions in the profit model — eBay publishes no per-account fee API.

      Send these offers to your watchers?

      Each watcher gets a private discount that expires in about 48 hours. Your public listing price does not change, and an offer cannot be recalled once sent.

      Local Image Generator Setup

      Checking for running image servers...

      Stability Matrix is a one-click manager for local AI image generation on Windows. It installs Python, CUDA drivers, and models automatically — no command line knowledge required.

      1. Click Download Stability Matrix below — this opens lykos.ai (official site)
      2. Download and run StabilityMatrix-win-x64.exe
      3. In Stability Matrix, click Add Package and choose ComfyUI or AUTOMATIC1111 Web UI
      4. Let it install — allow 15–30 minutes and about 20 GB of free disk space for models
      5. In the Models tab, download an SDXL model (e.g. Stable Diffusion XL Base 1.0)
      6. Click Launch in Stability Matrix to start your image server
      7. Click Test Connection below — this app will detect your server automatically
      Download Stability Matrix (lykos.ai)

      Install AUTOMATIC1111 Stable Diffusion Web UI manually. Requires Python 3.10 and Git. Recommended for users comfortable with the command line.

      1. Install Python 3.10 from python.org — tick "Add Python to PATH" during setup
      2. Install Git from git-scm.com
      3. Open a terminal and run:
        git clone https://github.com/AUTOMATIC1111/stable-diffusion-webui
      4. Edit webui-user.bat — set COMMANDLINE_ARGS=--api (required for this app to connect)
      5. Run webui.bat — first run downloads ~5 GB of dependencies automatically
      6. Once running, the server is at http://127.0.0.1:7860
      7. Click Test Connection below

      Install ComfyUI — a node-based Stable Diffusion interface. More efficient than AUTOMATIC1111, but requires manual model placement and checkpoint name configuration.

      1. Download the ComfyUI standalone Windows package from github.com/comfyanonymous/ComfyUI/releases
      2. Extract the zip to a folder such as C:\ComfyUI
      3. Download an SDXL model (e.g. from civitai.com or Hugging Face) and place it in ComfyUI\models\checkpoints\
      4. Run run_nvidia_gpu.bat (or run_cpu.bat if you have no NVIDIA GPU)
      5. The server starts at http://127.0.0.1:8188
      6. Enter the exact checkpoint filename in the Model Name field below (e.g. sd_xl_base_1.0.safetensors)
      7. Click Test Connection below
